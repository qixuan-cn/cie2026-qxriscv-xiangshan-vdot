## 7. 配置管理与提交规范

| 项 | 规范 |
|---|---|
| 分支 | `main`（可交付快照）/ `dev`（日常）/ `feat/*`（单项） |
| 标签 | `phase1`、`phase2`、`phase3`、`submit-v1` |
| 提交信息 | `<scope>: <动作> <对象>`，如 `rtl: add VDot functional unit`、`docs: add phase2 test report` |
| 版本锁定 | README 记录 `xs-env` 与 XiangShan 的 commit hash、Verilator 版本、NEMU commit；**全程不漂移** |
| 大文件 | 波形/视频不入库（Git LFS 或外链 + 截图），仓库保持轻量 |
| 香山源码 | **不全量入库**，用 `patches/` 下的 diff + 集成说明 + 上游 fork 链接与 commit 号 |
| 一键复现 | `scripts/run_all.sh`：构建 → 跑全部用例 → 输出汇总表 |

### 仓库结构（建议）

```
cie2026-<team>-xiangshan-vdot/
├── README.md                 # 一页读懂：是什么/怎么跑/结论是什么/版本锁定
├── docs/
│   ├── ipd/                  # 本套 00–04 文档
│   ├── phase1/               # 日志、hello、vadd 波形
│   ├── phase2/               # 设计文档、基础测试报告
│   └── phase3/               # 协同仿真、性能分析
├── rtl/                      # VDot.scala + 集成点说明
├── patches/                  # 对香山/NEMU 的 diff
├── tests/                    # 汇编用例、Python 模型、比对脚本
├── scripts/                  # 一键脚本、性能统计
└── video/                    # 录屏索引（或外链）
```
