赛题背景

香山，是中国科学院计算技术研究所牵头发起的开源高性能RISC-V处理器项目，也是目前国际上唯一基于RISC-V的开源高性能处理器系统。从处理器核到配套的互联网络、开发工具，香山实现全开源，打破了高端处理器IP的垄断，让每个人都可以自由获取核心技术、学习顶尖芯片设计。

点积（Dot Product）是深度学习模型的核心计算内核，在推荐系统、大语言模型（LLM）等AI应用中通常占据总计算量的60%–80%。在推荐系统中，78%的个性化推荐将点积作为核心排序指标，用于计算用户向量与商品向量的匹配度；在Transformer架构的LLM中，自注意力机制的矩阵乘法由海量点积构成，以GPT-2为例，点积占总计算量70%以上，其执行效率直接决定推理性能与能效，尤其在资源受限的边缘端更为关键。RISC-V凭借开源、模块化及可自定义扩展的优势，成为边缘AI处理器的主流架构。

通过自定义向量点积指令（vdot），可在处理器流水线中集成专用硬件加速单元，以极小面积开销换取数倍点积吞吐提升，满足边缘LLM对高性能、低功耗、低成本的需求。

“香山”昆明湖V2作为国产高性能RISC-V处理器，具备成熟的向量扩展与自定义指令接口，为vdot指令的硬件集成提供了理想的架构基础。

赛题内容

目标平台：“香山”昆明湖 V2 处理器（国产开源高性能 RISC-V 处理器）。

技术基础：具备成熟的向量扩展与自定义指令接口。

核心要求：复用香山昆明湖 V2 现有的向量实现，将 vdot 指令作为向量指令集中新增的自定义指令进行功能单元扩展。vdot.vv 指令语义（SEW = 8, VLEN = 128）

本赛题围绕香山昆明湖V2平台，设计并实现vdot向量点积自定义指令。三个阶段难度递进，评审将根据完成度逐级评价，无论你是本科生还是研究生，都能找到适合自己的挑战。



阶段一：环境部署，入门难度。

你需要按照香山操作手册完成开发环境部署，输出验证信息与操作日志，并基于仿真波形分析向量加法指令的执行过程。这一步让你快速上手真实的工业级处理器开发环境，为后续设计打下基础。



阶段二：设计与实现，中等难度。

根据vdot.vv指令语义（SEW=8，VLEN=128），完成设计文档和RTL实现，并基于香山仿真环境完成正数、负数、边界值三项基础功能测试。你将真正在香山向量执行单元中新增一条自定义指令，体验从指令定义到RTL编码再到功能验证的完整硬件开发流程，理解向量数据通路、符号扩展和累加器等关键模块。



阶段三：验证与优化，高难度。

为NEMU模拟器新增vdot指令，完成RTL与NEMU的协同仿真；用已有向量指令组合实现相同功能作为基线；对比基线组合与vdot专用加速单元的延迟，完成加速比分析。你将掌握软硬件协同验证方法，量化评估微架构优化的收益，学会用数据证明专用硬件加速的价值——这是处理器性能工程师的核心能力。

完成这三个阶段，你将收获一份完整的自定义指令设计交付物（设计文档、RTL代码、测试报告、性能分析），深入理解香山高性能处理器流水线与向量单元，获得软硬件协同仿真的实战经验，并有机会为国产开源CPU生态贡献代码，被社区收录。优秀成果将得到认可。

三个阶段由易到难，每一步都有明确的交付物和评审标准。无论你是初次接触RISC-V，还是已有硬件设计基础，都能在这个赛题中找到成长路径。香山社区和RISC-V生态系统将为你提供丰富的学习资源和技术支持
